# sn0wbite 🍎❄️

> *One bite is all it takes.*

**sn0wbite** is an experimental reverse engineering project aiming to run
watchOS on the OnePlus Watch 2R.

## Status
🚧 Early research — nothing boots yet. Expect broken things.

## Goals
- [ ] Bootloader analysis (Snapdragon W5 + BES2700)
- [ ] Custom loader / payload
- [ ] Kernel & hardware bring-up
- [ ] Display, touch, crown, sensors
- [ ] First boot screen
